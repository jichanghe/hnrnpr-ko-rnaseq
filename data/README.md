# data/

The sequencing data are not redistributed here.

1. Download the processed count data from GEO accession **GSE202720**
   (Ji *et al.*, *EMBO Rep* 2022), which holds the HNRNPR<sup>+/+</sup> and
   HNRNPR<sup>−/−</sup> HeLa RNA-seq used in this study.
2. Place the files in this directory, or point the paths at the top of each
   script at wherever you have put them (see the "Known issues" section of the
   top-level `README.md`).

The analysis output behind every plotted panel is in
`Source_Data_biology-4683043.xlsx`, published with the paper, so the figures can be
checked without re-running the pipeline.
